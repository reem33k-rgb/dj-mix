# djmix – מיקס DJ אוטומטי (טראנס / 4 על הרצפה)

סביבה: `~/dj-env` (Python 3.14, librosa, soundfile, scipy). המתיחה נעשית בפילטר rubberband של ffmpeg, עם Key Lock: הקצב משתנה והגובה נשאר.

## פקודות
```bash
~/dj-env/Scripts/python.exe ~/dj-mix/djmix.py analyze track1.mp3 track2.mp3
~/dj-env/Scripts/python.exe ~/dj-mix/djmix.py mix track1.mp3 track2.mp3 -o set.mp3
```

## מה `mix` עושה
1. ניתוח של כל טרק: BPM מדויק (אוטו-קורלציה של הקיק לאורך עד 256 ביטים), גריד ביטים, הביט הראשון בתיבה, פרזות של 8 תיבות, בריקדאונים וסולם (Camelot).
2. כל הטרקים נמתחים לטמפו של הסט. ברירת המחדל היא הטמפו של הטרק הראשון, ואפשר לקבוע אחר עם `--bpm`.
3. נקודת היציאה: תחילת הפרזה האחרונה שאורך המעבר נכנס אחריה עד סוף הטרק (בדרך כלל האאוטרו). הטרק הבא נכנס בפרזה הראשונה שלו (האינטרו).
4. כיוונון עדין עם קורלציה של הטרנזיינטים, בדיוק של פחות ממילישנייה (כמו לגלגל את הג'וג עד שההיי-האטים ננעלים).
5. המעבר:
   - הגבוהים של הטרק הנכנס עולים בחצי הראשון.
   - ב-bass swap (ברירת מחדל: אמצע המעבר) הבסים מתחלפים בבת אחת, בפחות מ-1/16.
   - הגבוהים של הטרק היוצא יורדים בחצי השני.
6. התאמת עוצמות לפי התיבות שיש בהן קיק, ובסוף limiter ב-0.89. הייצוא הוא MP3 320k או WAV 24bit.
7. נוצרים גם `*.tracklist.txt` עם זמני הכניסה והסוואפ, ו-`*.report.json`.

## אפשרויות
| דגל | מה עושה |
|---|---|
| `--bars 32` | אורך המעבר בתיבות (16/32/64) |
| `--swap 16` | באיזו תיבה בתוך המעבר מחליפים בסים |
| `--bpm 140` | טמפו הסט |
| `--out-bar 113 -` | לכל טרק יוצא: התיבה שממנה מתחיל המעבר (`-` = אוטומטי) |
| `--in-bar - 17` | לכל טרק: התיבה שבה הוא נכנס (הראשון מתעלמים) |
| `--semitones 0 1` | הזזת סולם לכל טרק |
| `--harmonic` | הזזה אוטומטית של ±1-2 חצאי טונים כשהסולמות מתנגשים |

מספרי התיבות הם כמו בפלט של `analyze` (מתחילים מ-1).

## בדיקה
`test_gen.py` מייצר טרקים סינתטיים, ו-`test/` מכיל מיקסים לדוגמה. נמדד היישור של ההיי-האטים בזמן החפיפה: סטייה של 0.2 מילישנייה, בלי כפילויות (flam).
